# 音效设计与智能卡点规范（CC0 曲库 + 同窗净抬升）

音效是百万剪辑师网感的「标点符号」——标题条弹出、大字砸下、贴纸跳入、画面闪切、天平落定，耳朵都要收到恰到好处的反馈，但绝不能吵成噪音或抢走人声。

## 一、素材来源与跨机器零配置兜底

1. **严禁代码粗糙合成白噪音效**：一律采用真实录音/专业设计的 **CC0 1.0 免版权音效**（`scripts/cc0_lib.py`）。
2. **双层解析**：
   - 若 `config.json` 配置了外置全量 `sfx_lib` / `bgm_lib`，优先从全量库挑选；
   - 未配置（如刚复制到另一台新电脑）时，自动无缝回退到随仓内置的精选包 `assets/audio/sfx`（24 条高频网感音效）与 `assets/audio/bgm`（5 首多情绪律动配乐）。
3. **商用授权留痕**：每次渲染成片自动输出 `out/sfx_manifest.json`，逐条记录用到的 BGM 与音效文件路径、SHA-256 指纹与 CC0 许可证明。

## 二、五大音效职责与自动轮换

| 事件类型 | 默认音色族 | 触发时机 | 混音策略 |
|---|---|---|---|
| **开篇冲击 / 闪切**（`punch` / `flash`） | `boom-cinematic-hit` / `whoosh-fast-hard` | 前 3 秒黄金钩子推镜、强反转切镜 | `t - sync_at` 峰值精准踩在切点帧上 |
| **顶部标题条 / 章节切换**（`title` / `gen`） | `whoosh-fast-soft` / `appear-materialise` | 标题条弹簧落位、整屏动效入场 | 轻盈过场，不压低频 |
| **大字花字 / MG 动效卡**（`keyword` / `behind`） | `pop-medium-in` / `impact-light-firm` | 锚词发声后 `+150ms` 卡片弹入 | 底音自动瞬态闪避（Ducking `90ms`） |
| **矢量情绪贴纸**（`sticker`） | `pop` / `ding` / `money` / `shimmer` | 随贴纸语义自动匹配（如算账配金币声、妙招配清脆叮声） | `-3.5 dB` 轻巧点缀 |
| **场景内物理动作**（`props.events`） | 按动作定义（砝码落盘、印章盖下） | 代码场景内部相对秒数映射至全片 | 连续同名自动触发 `rotate_sfx()` 换同族变体防听觉疲劳 |

## 三、混音铁律：先混音效、再做全片响度归一

- **BGM 处理**：先独立归一至 `−28 LUFS`，再由人声轨 `12:1` 侧链压缩（Sidechain Ducking）——人一开口音乐自动退后，停顿时音乐自然托底；时长不足时自动无缝循环。
- **SFX 混入**：必须在最终全片 `−14 LUFS` 响度归一**之前**混入，并在每处音效点对底音做 `90ms` 微让位，最后统一过自适应砖墙限幅器（真峰值 `≤ −1.0 dBTP`）。

## 四、可听度实测门禁（`scripts/check_sfx.py`）

渲染阶段自动留存混音效前的干净底音轨 `out/stem-nosfx.m4a`。`scripts/check_sfx.py --project <项目>` 在 **2–8 kHz** 瞬态频段将成片与底音做**同窗逐点相减**，实测每处音效自己的真实净抬升（`≥ 2.5 dB`），彻底杜绝异时对照带来的误判。
