## 三个节奏档

按 20 支片「画面变化中位」的 p25 / p50 / p75 切三档：

| 档 | band（画面变化中位） | 参考片落在这一档的 | 适合 |
| --- | --- | --- | --- |
| 快 | **1.9 – 2.2s** | 11 支 | 强观点、抢前 3 秒 |
| 中 | **2.2 – 2.7s** | 5 支 | 施工/过程、需要看清动作 |
| 慢 | **2.7 – 3.4s** | 4 支 | 认知类、需要消化 |

注意：这里的「中位」量的是**成片上画面变化的间隔**，不是素材里的机位切换。
两者差得远（我们 naming-01：素材机位中位 4.86s，成片画面变化中位 1.83s），因为叠卡、代码画面也在换画面。

## 每个判据的处置（含被降级的）

| 判据 | 阈值 | 依据 | 备注 |
| --- | --- | --- | --- |
| 镜头长 CV | **≥0.42** | 20 支片最低 0.417 | 外部方法用 0.25，太松：这批片没有一支低于 0.41 |
| 死静占比 | **不作判据** | 8/20 支接近 0 | 对短视频口播没有区分力 |
| 冻结 ≥2s | **只在口播段判** | 7/20 支有空镜冻结 | 全片判会误杀三分之一的行业成品 |
| 平均亮度 | **不作门，只诊断** | p50 0.391；外部「Y 30–60/255」= 0.12–0.235 会判死 19/20 | 只在均值 <0.10 或连续 1s <0.02 时报 |
| color tag | bt709 ×3 | 18/20 支有，2 支缺 | 我们的**自家规矩**，只判黄 |
| 音画等长 | `-0.05 ≤ 声轨−画面 ≤ 0.25` | 13/20 支声轨更长，最大 +0.155 | 反向才是事故：结尾静音/最后一字被砍 |
| 流起点差 | ≤ max(0.1s, 2/fps) | 20/20 都是 0.000 | 只看起点，末点不同是编码填充 |
| 承接通 | bare 边界 = 0 | 四支片的公开判决（0.00 被否 vs 0.56/0.75 通过） | 先在时间轴上判结构，像素探针留 v2 |
| 微事件间隔 | ≤1.2s | 外部方法：0.35–0.9s 一次；我们取 1.2 为上限 | 超过 1.2s 报黄 |
| B 轴准入 | 有叙事 + ≥8s + 三问齐 | 本地 `srt-motion-cards` 的准入规则 | 短于 8s 装不下「谁/遇到什么/怎么变」 |

## 重新标定怎么跑

```bash
# 20 支参考片 + 我们三支，一次量完（约 3 分钟）
python3 /tmp/rh/corpus.py        # 脚本在 /tmp，随时可重写；输出 corpus.json
```

样本换了（比如换了一个行业、换了一批素材）就重跑一遍，再改 `styles/catalog.json` 里的 band。
**不要**在没有新样本的情况下凭感觉改阈值——上一轮「凭饱和硬拉」就是这么翻车的。
