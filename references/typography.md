# 字体：四层各用各的，字号变了字也得变

> 这一页是 2026-11-08 Jerry 一句「字体简直不堪入目」逼出来的。
> 之前整片四个层（字幕 / 花字 / 字卡 / 身份卡）共用一个阿里妈妈数黑体，
> 而**所有检查全是绿的**——因为没有任何一项在量字形。

## 一、先说翻车是怎么发生的

1. 包装模板（`styles/` 下每一个 `pack-` 开头的 yaml）里只有一行 `font_class: sans_heavy`，
   `pack_style.FONT_CLASS` 把它映射成 `AlimamaShuHeiTi-Bold`。
2. 字幕、花字、字卡、身份卡四层**都走这一个映射**。
3. 阿里妈妈数黑体是**标题美术字**：笔画有粗细对比、末梢带切角。
   放大到 9.5%H 当花字时，这些特征是味道；缩小到 5.4%H 当字幕时，它们变成脏点。
4. `measure_pack.py` 量的是位置和字号，`compare_films.py` 量的是亮度和节奏，
   `verify_film.py` 量的是画幅、密度、响度——**没有一项看字形**。
   于是"在带内"四项全过，人一眼就看出不对。

结论一句话：**位置能量，味道量不了；味道只能靠"按层分配 + 人眼过一遍"来管。**

## 二、四层各用什么

| 层 | 字号 | 用什么 | 为什么 |
|---|---|---|---|
| 字幕 | 0.028–0.045H（54–96px @1080） | **思源黑体 SemiBold** | 长期阅读，笔画必须等粗；屏幕上的工业标准 |
| 花字 | 0.088–0.115H（170–220px） | **思源黑体 Black** | 放大近两倍，Semibold 会显瘦；Black 的重量能撑住描边 |
| 字卡 / 结构图 | 24–70px 混排 | **思源黑体 Bold** | 混排里有 24px 的脚注，小字最吃分量 |
| 身份卡 | 30–66px 四行递减 | **思源黑体 Bold** | 同上；四行靠明度分层，不靠换字体 |
| 宋体族（B 族签名） | 任意 | **思源宋体 Bold** + 投影 | 宋体描边会糊笔画，模板里写 `stroke: none` 强制走投影 |

三件事同时成立才算对：

- 字幕的字体**不许出现在标题美术字清单里**（`阿里妈妈数黑体 / 方正兰亭大黑 / 汉仪尚巍手书…`）；
- 字幕和花字**不许是同一个字体**——同一个字体能同时当好这两层，几乎不可能；
- 花字**不许比字幕轻**。花字的意义是"这一句要从画面里跳出来"，重量必须盖过字幕。

## 三、模板里怎么写

```yaml
subtitle:
  font: 思源黑体 SemiBold      # 直接写字体名，不再走 font_class
emphasis:
  font: 思源黑体 Black         # 花字单独指定
fonts:
  card: 思源黑体 Bold          # 卡面（字卡/身份卡/结构图）单独指定
```

`font_class` 还留着兼容老模板，映射已经改过：`sans → 思源黑体 SemiBold`，
`sans_heavy → 思源黑体 Bold`，`display → 阿里妈妈数黑体`（只许用在标题上）。
新增 `sans_display → 思源黑体 Black` 给花字用。

**换字体必须重算字号**：`size_for_glyph()` 量的是真字形墨迹高，不同字体的墨迹/em 比
差 25% 以上（思源 0.88em，阿里妈妈数黑 0.75em）。沿用上一版的 `size_px` 会让新字体小一圈。

**ttc 必须写 face 序号**：PIL 的 `truetype(path)` 默认拿第 0 个 face，
苹方第 0 个是 `PingFang HK Regular`——不是你要的那个。不写序号会静默拿到错字重。
`FONT_LIB` 里已经把苹方 SC 的 Regular/Medium/Semibold 都标了序号（3 / 7 / 11）。

## 四、怎么复核（这是这一页的重点）

按"能机器判 / 只能人判"分两半，别混着说。

### 机器能判的（已进验收）

```bash
python3 scripts/verify_film.py --project <项目> --style styles/pack-warm-keyword.yaml
```

新增一行 **字体分层**：

| 情况 | 结果 |
|---|---|
| 字幕用了标题美术字 | 🔴 `字幕用了标题美术字（大字号有魂，小字号是脏点）` |
| 字幕和花字是同一个字体 | 🔴 `字幕与花字同一字体（四层共用一个是这次翻车的根因）` |
| 各层分开了 | 🟢 `字幕 思源黑体 SemiBold · 花字 思源黑体 Black` |

这条检查只挡得住"结构错"，挡不住"这个字体丑"。丑必须人看。

### 人眼看之前，先把候选摆成一张卡

```bash
python3 scripts/font_sheet.py --w 1080 --glyph 54 --out /tmp/fonts.png
python3 scripts/font_sheet.py --text "成本贵在哪" --glyph 182 --out /tmp/emph.png
```

同一句话 × 11 种字体 × 两种底色（中灰 / 近黑），字高按**墨迹高**对齐，
描边宽度按墨迹高的比例给。这样比出来的差异才是字形本身的差异，
而不是"字号没对齐"或"描边宽了一点"。

### 想从参考片反推字体：`match_font.py`（有上限，别当成答案）

```bash
python3 scripts/match_font.py --video 参考片.mp4 --t 19 --text "这都是我们|绕不开的坑啊"
```

做法是模板匹配：把参考帧的白字抠成掩膜 → 紧致裁切 → 每个候选字体渲同一串字 →
缩放到同尺寸 → 算 IoU，按**字体族**排序（同族不同字重只差 0.03，那是噪声，
判族才有意义）。

三条实测边界，写在前面免得白跑：

1. **源分辨率决定上限。** 576×1024 的参考片里字高只有 29 像素，IoU 到 0.75 已经很高；
   1080 宽的自制素材能到 0.88 并稳定认出族。
2. **背景亮就抠不出字。** 白字压在浅色背景（白板、水泥地、亮衣服）上时，
   阈值法会连背景一起吞进来。换一帧、或者等片子自己切到暗场。
3. **认不出就写认不出。** 前两名差不到 0.06 时脚本直接说"别硬认"。
   凭一个 0.02 的差距宣布"参考片用的是 X"，比不知道更糟。

自检（不依赖任何素材，能直接验证工具本身没坏）：

```bash
python3 - <<'PY'
from PIL import Image, ImageDraw, ImageFont
img=Image.new("RGB",(1080,1920),(30,30,32)); f=ImageFont.truetype("/Users/jerry/Library/Fonts/NotoSansSC-SemiBold.ttf",60)
d=ImageDraw.Draw(img); t="不管珠海的、广州的、上海"
d.text(((1080-d.textlength(t,font=f))/2,1340),t,font=f,fill=(255,255,255),stroke_width=3,stroke_fill=(0,0,0))
img.save("/tmp/dark_sub.png")
PY
python3 scripts/match_font.py --video /tmp/dark_sub.png --t 0 --text "不管珠海的、广州的、上海" --band 0.6 0.8
# 期望：最像 思源黑体（领先第二名 0.081，可以认）
```

## 五、这一页给产线留下的一步

`fonts:` 是模板里的**必填字段**吗？不是——不写会落到 `FONT_CLASS` 的默认值，
而默认值已经是对的（字幕 SemiBold / 花字 Black / 卡面 Bold）。
写它只在你需要偏离默认时。

所以新库冷启动不需要做任何字体决策，**但新模板要人眼看一次 `font_sheet.py` 的输出**——
这一步目前没有自动化，也不该自动化：字号和位置可以量，"这个字在这个字号上好不好看"
只能由看片子的人定。
