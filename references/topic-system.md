## 4. 开篇钩子八大切入点（原文就八条，编号只用于对话指代）

全部出自 [原文『内容创作』一节 · 水桶流视频 · 开篇钩子八大切入点](content-system.md#水桶流视频)。**原文没有编号**，下表编号是本卡为了对话指代加的，引用时仍以名称为准。

| 序 | 切入点 | 原文的公式 / 要点（照抄） |
|---|---|---|
| 1 | **人群切入** | `身份标签 + 应该做什么/注意什么/揭秘 + 核心话题/承诺`；要点是让特定人群觉得「说的就是我」 |
| 2 | **痛点切入** | `你是不是遇到过（痛点场景）+ 糟糕的感受/结果`；要点是不同人群关注点不同，围绕人群或行为现象挖痛点 |
| 3 | **效果切入** | `方法/产品 + 时间/条件 + 惊人效果/承诺`；要点是效果前置 |
| 4 | **情绪切入** | `情绪/感受词 + 引发情绪的事件/对象 + 解决方案/共鸣点`；原文明说最强的四种情绪是「争议，共情，恐吓 痛苦」，并且情绪不单独使用、要与其他条线融合 |
| 5 | **好奇切入** | `反常识/反认知的结论 + 暗示有内幕/原因`；要点是说出超出认知的现象，让人想问为什么 |
| 6 | **身份推荐切入** | `权威/资深/亲临者身份 + 时间/经验 + 自我总结/教你/揭秘 + 价值点`；两种来源：达人明星直接推荐、真实用户的自我见证 |
| 7 | **颠覆切入** | `开篇第一句 = 先说行业常识，其实/但颠倒他` |
| 8 | **疑问切入** | `为什么/怎么样 + 一个普遍存在的难题/现象` |

### 4.1 人格化表达六大切入点

同样出自 [原文『内容创作』一节 · 水桶流视频 · 人格化表达六大切入点](content-system.md#水桶流视频)：

| # | 切入点 | 原文的核心句（照抄/节引） |
|---|---|---|
| 1 | **性格** | 不要做完美的老好人，要做有明显性格标签的人（较真型 / 倔强型 / 温柔型 / 直爽型） |
| 2 | **初心** | 告诉用户你为什么一开始做这个事情，让用户理解你的出发点 |
| 3 | **原则** | 告诉用户，你坚持什么、不做什么，让用户知道你的底线 |
| 4 | **经历** | 告诉用户你走过什么样的路；原文说经历是最容易引发共鸣的切入点 |
| 5 | **价值观** | 核心是「我认为什么是对的」；用户认同你的价值观就会认同你这个人 |
| 6 | **态度** | 核心是「我认同什么不同」；比价值观更当下、更具体 |

> 每个切入点的原文样例句（「我宁愿少卖10单…」「开店一年我亏了30w…」等）在原文该节，引用必须抄原句，不许改数字。

## 7. 自建扩展（非原文，用前必须显式声明）

以下内容**原文没有**，是 CutSkills 为了对话可用性自己加的。引用时一律写「自建扩展，非原文」。

### 7.1 编导八大问（**自建扩展，非原文**）

用于「用户只说了一句『帮我做条视频』」时挖真人细节，**每次最多问 2 题**，不许连续审讯：

1. 最近哪个客户问的一个问题让你印象最深？
2. 同行最爱忽悠外行的一句套话是什么？
3. 你做这事最较真、别人觉得你「傻」的一个细节是什么？
4. 有没有一次差点翻车或赔钱换教训的真事？
5. 如果朋友私底下问你「到底怎么选」，你会用哪句大白话劝他？
6. 你这东西跟便宜一半的货，摆在一起肉眼哪一处差别最大？
7. 客户付完钱最常夸你的一句原话是什么？
8. 你最不想接哪一类客户的单？

### 7.2 三流向提案（**自建扩展，非原文**）

产品侧一次给 3 套提案（泛流量破圈 / 人设信任 / 垂直意向转化），是为了让用户做选择题而不是被审讯。三条流向的**档位归属与占比口径必须回原文 §1**：提案里标注的 A 层级与占比，只能是原文三阶段里真实存在的那一档配比。

## 9. 引用格式（给 Agent 的硬要求）

提案、脚本、拍片卡里凡是用了本文的能力，必须能指出原文位置，三种写法任选其一，但**必须带原文出处**：

1. 「钩子：痛点切入（原文『内容创作』一节 · 水桶流视频 · 开篇钩子八大切入点）」
2. 「话题：认知话题（原文『内容创作』一节 · 漏斗流视频 · 六大话题选题方向）」
3. 「结构：观点+原因+案例+观点（原文『文案框架内容』一节 · 中间内容）」

用了 §7 的自建内容，就写「编导八大问（自建扩展，非原文）」。
