# 上游选题与脚本创作系统（双流向引擎）

> 面向人群：**完全不懂编导、不懂拍摄、不懂剪辑包装**的业务主理人、实体店主、知识创作者与个体创业者。
> 核心任务：在动刀剪辑前，帮用户想出**自带流量又能转化**的选题、写出**像真人说话**的口播/旁白稿、并给出一张**拿手机 10 分钟就能拍完（甚至零实拍全靠代码生成）**的准备清单。

---

## 一、内容配比与双流向模型（5A 人群漏斗）

做账号最怕两件事：要么自嗨讲产品没人看（有转化无流量），要么纯蹭热点引来一堆白嫖党（有流量无转化）。用 **5A 人群配比**把选题分成两条流：

| 流向 | 对应人群 | 占比建议 | 核心公式 | 解决什么问题 |
|---|---|---|---|---|
| **漏斗流**（破圈拉新） | **A1 泛流量人群**（还不认识你，但关心自身痛点/热门话题） | **50%** | **自带流量的话题 + 强相关干货 + 自然顺手植入** | 高播放、破圈、拉新关注 |
| **水桶流 · 人设**（建立信任） | **A2 信任人群**（知道你，看你顺不顺眼、靠不靠谱） | **30%** | **真实经历/原则/态度 + 现场细节 + 价值观共鸣** | 立住专业与真人感，防同质化 |
| **水桶流 · 转化**（打消顾虑） | **A3 垂直意向人群**（想买，但怕踩坑、怕贵、怕麻烦） | **20%** | **客户深层顾虑 + 硬核对比证据 + 低门槛行动** | 私信咨询、到店、成交 |

- **起号三阶段调整**：
  - **冷启动期（第 1–10 条）**：漏斗流 60% + 人设 30% + 转化 10%（先把播放池撬开）。
  - **稳定期（第 11–30 条）**：50% : 30% : 20% 标准循环。
  - **收割/节点期（活动/旺季）**：漏斗流 30% + 人设 30% + 转化 40%。

## 二、怎么找选题（不用拍脑袋的三把尺子）

### 1. 漏斗流找大流量话题三法
1. **目标人群身份关联**：你的客户平时给自己贴什么标签？（例：宝妈、装修小白、小微老板、熬夜打工人）
2. **高频消费场景关联**：他在什么具体时刻最头疼？（例：刚拿毛坯房钥匙那天、月底算账发现没利润那天、周末带全家找地方喝早茶）
3. **生活角色冲突关联**：他怕在谁面前丢面子或吃亏？（例：怕被包工头忽悠、怕请客点菜踩雷）

### 2. 水桶流挖客户五层问题（越往下越有杀伤力）
不要只答第 1 层「多少钱」，往下挖到第 3–5 层才是高赞选题：
1. **显性问题**：怎么买、多少钱、做多久？（例：「刷艺术漆多少钱一平？」）
2. **隐性问题**：用久了会出什么毛病？（例：「住进去两年边角会不会起皮发霉？」）
3. **核心需求**：他买这东西真正想换来什么结果？（例：「花小钱做出酒店大堂的高级感」）
4. **决策障碍**：他迟迟不敢下单是怕什么？（例：「怕小店收了定金跑路、怕样板好看上墙翻车」）
5. **价值观认同**：他愿意为哪种做事态度买单？（例：「宁可少接两单，收边保护没做够绝不开喷」）

### 3. 人格化表达六切入点（让观众记住「你这个人」）
- **性格**（较真、毒舌但实在、慢性子死磕细节）
- **初心**（当初为什么入这行、受过什么刺激）
- **原则**（哪类钱坚决不赚、哪道工序绝不省）
- **经历**（踩过的最大一个坑、最难忘的一个客户）
- **价值观**（怎么看同行乱象、怎么看便宜没好货）
- **态度**（遇到翻车怎么赔、敢不敢把底牌亮出来）

## 三、黄金前 3 秒：十大高网感钩子（Hook）

短视频前 3 秒只有一个任务：**让手指停下来**。严禁「大家好我是某某，今天给大家分享……」这类废话开场！每条选题必须从下面十种钩子里挑 2–3 个备选：

| 代号 | 钩子类型 | 句式模板 | 为什么抓人 |
|---|---|---|---|
| `H01` | **不字/禁止开头** | 「千万别在……之前做……！」 | 损失厌恶，瞬间触发危机感 |
| `H02` | **反常识颠覆** | 「你以为……其实恰恰相反！」 | 打破固有认知，制造认知缺口 |
| `H03` | **具体数字反差** | 「花了 300 万装 600 平，三分之一全砸在了你看不见的地方。」 | 具象数字天然比形容词可信十倍 |
| `H04` | **做观众嘴替** | 「是不是每次去……都被这句话忽悠过？」 | 一秒站到观众同一战线 |
| `H05` | **制造共同敌人** | 「这行最坑人的套路，今天我把底裤扒给你看。」 | 情绪张力拉满，完播极高 |
| `H06` | **身份背书切入** | 「干了 12 年……我自家装修死活不用这三样东西。」 | 内行人自曝，天然高权威 |
| `H07` | **痛点直球疑问** | 「为什么同样花两万块，别人做出来像展厅，你家像出租屋？」 | 精准扎进核心落差 |
| `H08` | **稀缺/内幕揭秘** | 「90% 的老板绝不会告诉你的成本账，算完你就懂了。」 | 窥探欲 + 实用收藏价值 |
| `H09` | **现场冲突切入** | （直接放砸掉重做/对比翻车画面）「看好了，这就是省那两百块钱的下场！」 | 视觉先行，冲击力最强 |
| `H10` | **结果倒叙炫技** | （先放惊艳成品 1.5 秒）「只用 36 小时，把老破小翻成这样是怎么做到的？」 | 结果诱饵，勾住人看过程 |

## 四、编导启发八大问（给 AI Agent 的不打扰引导守则）

用户说「帮我做条视频」但没给细节时，**严禁像查户口一样连抛八个问题**！
- **守则 1（先猜后问）**：根据用户一句话先生成 3 个不同流向的选题提案，让用户做选择题（输入 `1 / 2 / 3` 就能走）。
- **守则 2（每次最多问 2 题）**：只有需要真人细节时，从下面八问里挑最关键的 1–2 问：
  1. 最近哪个客户问的一个问题让你印象最深？
  2. 同行最爱忽悠外行的一句套话是什么？
  3. 你做这事最较真、别人觉得你「傻」的一个细节是什么？
  4. 有没有一次差点翻车或赔钱换教训的真事？
  5. 如果朋友私底下问你「到底怎么选」，你会用哪句大白话劝他？
  6. 你这东西跟便宜一半的货，摆在一起肉眼哪一处差别最大？
  7. 客户付完钱最常夸你的一句原话是什么？
  8. 你最不想接哪一类客户的单？

## 五、六套高完播脚本结构与四式收尾

### 脚本骨架（按 35–60 秒黄金时长，约 150–260 字）
1. **观点锤击式**（适合漏斗流科普）：`3秒暴击钩子 → 一句话反常识结论 → 2个肉眼可见的原因/对比 → 一句话金句收尾`
2. **结果倒叙式**（适合手艺/改造/案例）：`惊艳结果画面 + 悬念数字 → 当初遇到的死局 → 关键一招破局 → 感悟收尾`
3. **避坑拆招式**（适合 A3 转化）：`嘴替点出痛点 → 揭秘行业猫腻 → 教观众一招自测方法 → 顺手亮自家标准`
4. **成本算账式**（高收藏率）：`反差总账开篇 → 拆开三笔明账暗账（配比例条/天平动效卡） → 怎么花钱最值`
5. **故事反转式**（适合 A2 人设）：`冲突开场 → 所有人都劝我凑合 → 我偏死磕到底 → 最终反转结果`
6. **快问快答式**（高密度信息）：`连抛 3 个高频误区 → 噼里啪啦逐个打脸（配节奏卡点 + 贴纸） → 总结口诀`

### 四式收尾（绝不烂尾，也别硬广劝退）
- **金句式**：浓缩成一句 10 字以内好记的顺口溜，促转发收藏。
- **互动争议式**：抛一个二选一问题（「换作是你，选省两千块还是选十年不起皮？」），骗评论区吵起来拉高推流。
- **人设态度式**：亮出底线（「我是某某，宁可少接单绝不糊弄收边」），圈铁粉。
- **钩子留白式**：给下期埋扣子或自然引导主页/私信领清单。

## 六、小白傻瓜拍片指南（零行话规则）

给不懂拍摄的用户出准备清单时，**禁止出现「B-roll、景别、大光比、景深、构图三分法」等专业黑话**（若必须提术语，括号内立刻用大白话释义）：

1. **怎么站、怎么拿手机**：手机**竖着拍**，镜头擦干净！面对窗户站（让自然光照在脸上，千万别背对窗户拍成黑脸），手机架在跟眼睛差不多高的位置，离自己一臂远。
2. **怎么说话最省事**：**不用背全文！** 看一眼写好的逐句台词，念一句、停顿一秒、再念下一句。中间念瓢了、卡壳了**千万别关机重头录**，深吸一口气把刚才那句重念一遍就行——我们的剪辑程序会自动把念错的废话和停顿剪得干干净净。
3. **补拍 3 个「手头动作画面」（画面素材）**：除了对着镜头说话，顺手拿手机贴近拍 3 段每次 5 秒钟的动作（比如：手摸材质表面、两个样品摆一起对比、正在干活的手）。**拍的时候手稳住不动数 5 秒**，开头结尾别乱晃。
4. **拍不出来的交给代码画**：凡是涉及算账对比、比例拆解、流程步骤、抽象原理的画面，清单里直接标明 **「不用拍！由 CutSkills 代码自动生成高级动效卡」**；连口播都不想自己录时，标明 **「不用录！可由 AI 配音直接生成」**。
