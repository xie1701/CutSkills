# 对抗式审查 · 2026-11-11

不是「再验一遍」，是**想办法把上几轮的结论打翻**。攻击面按「最容易被我说成真的」排：
① 配置写了一件事、片子做另一件事；② 判据自己给自己打分；③ 判据里藏着旧假设；
④ 结论只在玩具数据上成立。

每条都带复现命令和数字。**「假」= 声称的能力在代码里不存在或没生效。**

---

## A. 抓到的假（已修）

### A1 · P3「无字幕层」是假的：“18 条字幕照渲”

- 声称：`packs/P3-dark.yaml` 的 `subtitle_system.id: none`，「大字即字幕」。
- 攻击：`grep -rn subtitle_system scripts/` → 只有 `render_style_preview.py`（样张）和
  `check_packs.py`（检查器）读它，**渲染器根本不认**。
- 证据：真项目 `qizao-naming-01` 用 `--style P3-dark` 渲出来的 HTML 里
  `class="clip cap"` **18 条**，和 P1-warm 一模一样。
- 修：`render_hf` 读 `subtitle_system`（none 关字幕层 / bilingual 没英文稿就明说）。
  修后同一项目：**字幕 0 条 · 大字 3 块**，成片字幕带白像素 0.00%（P1-warm 5.97–8.60%）。

### A2 · 换包装试一次，会把项目的字幕数据清空

- `out/subs.json` 写的是**这一轮渲出来的字幕**，不是片子里真实存在的字幕。
  P3（无字幕层）渲一次 → `cues: []`。**我自己就踩了一次**：18 条变 0 条。
- 修：`cues` 记全量 + `suppressed: true` + `subtitle_system` 字段；渲片用的 `caps` 另算。
- 证据：修后 P3 渲完 `cues: 18 · suppressed: true`；重渲 P1 `cues: 18 · single-line`。

### A3 · 「换 look 不动切点 ✅」的第一版判据，在真项目上恒为真

- 判据用 `<div class="clip" ...>` 抽视频轨。但实拍格是 `<video class="clip">`，
  只有整屏 gen 卡才是 div。于是真项目上抽出来 **0 格**，`0 == 0` → 「一致 ✅」。
  一个永远不会失败的自证。
- 修：任意标签 + class 含 `clip` + 排除字幕/大字/身份卡/抠像轨，**按起点排序**
  （文档顺序里代码画面的 `<video>` 排在实拍格后面，直接比会误报）。
- 修后真项目 P2-paper 与 P3-dark 抽出来都是 9 格，逐格一致。

### A4 · 判据里藏着旧包装的颜色假设：「三块大字明明在，判成 0.00%」

- 「大字烧进画面」查的颜色写死 `emphasis.keyword_color`（暖金黄 `#F6EB34`）。
  P3-dark 的 accent 是青 `#39D0C4` → 大字在画面上，判据说「几乎为零」，**3 条假红**。
- 修：候选色从当前包装的 `tokens.palette.accent` + `emphasis.keyword_color` 取，占比取最大。
- 证据（同一支 P3 成片）：修前 **🟢16 🔴5**，修后 **🟢19 🟡1 🔴1**，剩下的红是真问题。

### A5 · 验收读的包装 ≠ 渲片用的包装

- `render_hf --style P3-dark` 只是命令行覆盖，时间轴里仍写着 `pack: P1-warm`；
  `verify_film` 照时间轴读 → 拿 P1 的参数验 P3 的片。
- 修：验收按「`--style` → `hf/meta.json` 的 style（渲染那一步自己记的）→ 时间轴 pack → style_pack」排。
- 这一条和 A4 叠在一起才会出假红；单修一条不够。

### A6 · `gen_scene --probe` 对「亮而全静止」判绿

- 攻击：造一个纯静止的亮画面喂进去。旧判据只看亮像素 → **🟢 100% 收尾有东西**。
  而「0.5s 和 4s 一模一样」正是这批场景被打回的原病。
- 修：probe 加三项——最长静止（判据 <2s）、动帧比例（<30% 判红）、帧差中位（给人看）。
- 证据：`lime` 最长静止 0.62s / 动帧 83% / 帧差中位 1.01 🟢；
  静止亮画面 最长静止 3.88s / 动帧 0% 🔴；全黑画面 🔴。

### A7 · 「代码画面会不会冻住」在成片层面没人看

- `--probe` 只在**画的时候**跑，渲进片子之后没人复核。
- 修：`verify_film` 新增「代码画面 #N 不是静图」，从**成片**取 6fps 小帧算最长静止。
- 证据：naming-01 #6 `0.17s`、#8 `0.33s` 🟢（帧差中位 2.07 / 2.68）。

### A8 · `style_menu --choose` 选了不算

- 菜单只写 `brief.json{plan,pack}`；`render`/`verify` 读的是 `timeline.json`。
- 证据：`timeline.py` 从来不写 `plan`/`pack`；`schema_upgrade` 一律填 `S2-live-mid`/`P1-warm`。
  菜单里选 S3 + P2，片子还是 S2 + P1。
- 修：`timeline.py` 写时间轴时带上；`render_hf` 认 `brief.pack`；`verify_film` 认 `brief.plan`。
- 证据：把 demo 时间轴里的 `pack`/`plan` 删掉、只留 `brief.json`，渲出来仍是宋体 + `--ground:#F2EDE3`。

### A9 · P3-dark 的 `fit_width: 0.82` 违反「大字撑 70%」硬规则

- Jerry 2026-11-09 定的：大字单排、撑画幅 70%。P3 写了 0.82，等于悄悄放宽。
- 修：改回 `0.70`，并在 `check_packs` 加判据（>0.72 判红）——这种数字最容易被
  「这套风格想更满一点」这种理由改掉。

### A10 · `npx` 并发撞锁被当成「HTML 有错」

- 两条链路同时跑 `npx hyperframes lint` → `ECOMPROMISED / Lock compromised`，
  被读成「lint 1 error，先别渲」，查半天 HTML。
- 修：认出这两个字样就等 4s/8s 重试，仍失败才认。

## B. 半真（能跑，但结论比说的小）

### B1 · 「3 支微样片」是 6 秒纯代码占位，而且第一版三支字节数相同

- P1-warm 与 P3-dark 首版 md5 不同但体积一样（192.7 KB）：因为 `.gen` 的颜色写死，
  代码画面压根不吃 token。**换的是文件名，不是脸**。
- 修（P2 内已做）：token → CSS 变量，底色实测 `#17120f / #efece1 / #080a0c`。
- 仍小：样片只有 keyword + compare 两格、静音，**证不了动效和节奏**，也只覆盖两个模板。

### B2 · P2「双语双行」：没有英文源

- 全链路没有一条 cue 有 `en` 字段。渲出来仍是单行。
- 现在：`render_hf` 会打一行明说的提示，`check_packs` 判黄。
- 要真做：先有英文稿（翻译是一条独立工序），或者把 P2 的字幕体系改成 single-line。

### B3 · P3 的 `fx` 三样还不存在

- `morph_carry / sweep / particles` 写着，代码里没有。`check_packs` 现在会把它们点出来
  （警告不判红）——声明可以先行，但不许装成已经有了。

### B4 · 「节奏落档」量的是像素变化，会被字幕/卡片污染

- 同一支片：P1-warm（有字幕）视觉切点 **14**、中位 1.67s；P3-dark（无字幕）**13**、1.75s。
- 差的那一刀在 23.6s，是字幕出现造成的像素变化，不是剪辑点。
- 说明污染存在但量级小（1 处 / 41 秒）。**但这也说明「画面变化中位」不能当剪辑节奏用**，
  它测的是「画面变没变」。判词「减卡或减动效」在把字幕也算进去了。

### B5 · 石灰基三幕还没接进时间轴

- B 轴准入要求这一格有 `audio`（`check_timeline` 会拦），demo 还是静音样片。
- 已验的部分：12s / 最长静止 0.62s / 收尾亮像素 30.2%（峰值 30.5%）。

## D. 这轮审查本身的方法教训

1. **判据必须用「见过的错」校准**，不能用「跑通了」校准。A3 那条判据我上一轮是拿
   2 格玩具项目验的——它恰好是 div 形态，于是永远绿。
2. **判据里不许出现具体品牌的颜色/字号**，只能从当前这套包装里取（A4）。
3. **「渲染器读的是什么」和「配置写的是什么」必须对上**，这轮抓了三处（A1 / A5 / A8）。
4. **验收要打自己的脸**：造负样本（全黑、静止亮画面、混了时间字段的假包、没叙事的 B 轴格），
   四个都判对了才敢说判据有用。
