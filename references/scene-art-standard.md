# 代码画面的美术标准（scene art standard）

这份文件管一件事：**代码画出来的画面，什么叫做「像东西」，什么叫做「像 PPT」。**
判据要能量，判词不许用形容词。

写它是被两次打回逼出来的：2026-11-14 凌晨两套场景（排队打勾 / 双盘计数）
视觉复核三轮全是「PPT 图形」；同一天天平卡第一版把托盘画在横杆**上方**，
视觉模型三次都描述成「吊在杆下方」——它读的是常识里的天平，不是画面。

沿用的上位原则见 [editorial-packaging-principles.md](editorial-packaging-principles.md)：
**B14 有实拍就不画**。本文只管「决定要画之后，怎么画得站得住」。

---

## 0. 先过准入门槛（不过就别画）

| 门槛 | 判据 | 不成立怎么办 |
|---|---|---|
| 库里真没有 | 逐格接触表 + 视觉复核都找不到能拍这层关系的画面 | 用实拍（B14 优先级第一） |
| 也拍不出来 | 不是「这次没拍到」，是这件事本身没有可拍的外形（抽象关系、量、时间） | 退回信息卡，不上代码画面 |
| 有修辞关系 | 能说清「谁和谁之间是哪种关系」（更重 / 更慢 / 更挤 / 差一截 / 换了对象） | 说不出关系 = 只是把字变好看，别画 |
| 有实体可借 | 关系能落到一个有重量、会变、有前后左右的实物上 | 只左右摆的等宽色块永远读成图表 |

---

## 1. 形状即语义（比美术更靠前的一条）

观众先读形状，再读字。所以：

- **把关系画成物理**：不等价 → 天平；积压 → 越堆越高；延误 → 队列卡住；差额 → 一段空缺。
- **画出的每一块都要有物理归属**：砝码要坐在盘里、盘要挂在杆上、杆要架在支点上。
  第一版天平把三者的上下关系画反了，画面照样「好看」，但读起来是图标——
  因为没有任何东西在支撑任何东西。
- **尺寸关系要真**：5 块对 1 块就是 5 块对 1 块，别为了构图补到「看着平衡」。
  回平的时候两边必须真等量，否则观众会觉得被骗（这是可量判据，见 §4）。
- **一处只有一个变化**：一格画面里只演一件事。同一格里既补砝码又换角度又出结论，
  观众一个都没接住。

## 2. 伪 3D 三面律

二维 SVG 要读成实物，每个实体至少画三块：**顶面 + 正面 + 侧面**，加一道上棱高光。
少一块就是卡片；三块齐了才是块。

- 进深 5–7px（900 宽画布），别超过实体厚度的 1/2，否则像等轴测示意图。
- 顶面最亮（受光）、正面中调、侧面最暗；三面的差要肉眼可辨（ΔL ≥ 8）。
- 光的方向**全画面一致**（本项目一律左上受光）。
- 圆柱/横杆用垂直渐变 + 一道镜面高光带 + 一道底部暗边；再加一层细横纹（brushed）
  就够，别加噪点贴图。

## 3. 接地律（Grounding）

没有接地阴影的实物一律读成浮在屏幕上的图标。

- 站在地上的东西：脚下必须有投影椭圆，模糊半径 ≥ 实体高度的 12%。
- 挂着的东西：吊线要连到**杆的实体上**，倾动时线端与杆端一起走（缓动同参数）。
  第一版杆倾 9° 而盘只移 46px，理论位移 53px，脱开 7px——这是量出来的，不是看出来的。
- 盘里的东西：每块砝码脚下一层薄阴影（不透明度 0.3–0.5，模糊 3–4px），
  块与块之间靠顶面高光分层，不要靠描边分家。

## 4. 可量判据（渲完必跑）

```bash
# 几何：实体带 / 上下关系 / 斜率
python3 scripts/measure_geom.py --frame <帧.png> --what gold,order,shift

# 动静：动帧占比 / 最长静止 / 帧差中位
python3 scripts/measure_motion.py --video <场景.mp4> --fps 10
```

| 判据 | 门槛 | 量的是什么 |
|---|---|---|
| 上下关系 | 码垛在横条**下方** | 有没有倒着画 / 悬空 |
| 倾斜 → 回平 | 起始帧 \|倾角\| ≥ 4°，落定帧 ≤ 0.6° | 动作到底演完没有 |
| 数量对账 | 两侧块数与 `props` 声明一致 | 「5 对 1」有没有被画成别的 |
| 动帧占比 | ≥ 0.85 | 有没有大段站桩 |
| 最长静止 | < 1.2s | 有没有「卡住了」的段落 |
| 帧差中位 | 代码场景 1.2 – 6.0；**实拍段不适用**（手持、推镜天然更大，给 `--median-band 6:20`） | 动得没分量 / 抖成频闪 |
| 确定性 | 同参数两遍渲染哈希一致 | `test_scene_determinism.py` |

**判据必须有负样本。** 第一版倒画的天平就是它的负样本：
`measure_geom --what order` 必须报 🔴。报不出来的判据等于没写。

## 5. 颜色与字体

- 只用包里的 `tokens.palette`（暖陶土 / 黄铜 / 米白这一族）。
- **禁**：科技蓝、霓虹、紫粉渐变、玻璃拟态。这些一上屏就把「工地/餐馆/建材」拉成 SaaS 发布会。
- 强调色一格里最多两处（数字、结论行），其余靠明度分层。
- 中文用包里的 SC-Sub / SC-Big，字重只分「标题 900 / 正文 600」两档。
- 数字用等宽数字（`font-variant-numeric: tabular-nums`），否则动画中位数会跳。

## 6. 运动

- 入场 0.24–0.34s，`power2.out`；涉及「落下」的用 0.24s + 轻微下压，
  别用弹跳（bounce 在这类纪实片里像玩具）。
- 结论行在**动作落定之后** 0.4–0.6s 出，留到卡末；
  挂在通用收尾动画上会被压到卡末 0.45s（实测过，那行字等于没出现）。
- 连续微动：呼吸位移 ≤ 2px、光晕脉动 ≤ 4% 亮度。够把「静止」判据过掉，
  不够让人分心。不要用循环旋转/闪烁。

## 7. 声音

- 每个关键动作一个事件（`props.events`，场景内相对秒），落在动作**起点**上；
  同音色连续两次要换变体（`cc0_lib.pick_sfx` 的 `nth`）。
- 宁少勿满：8 秒的格子里 2–4 个事件。每个动作都配音 = 关节咔咔响的机器人。
- 结论/留白处不出声，让口播独自站住。
- 一律 CC0，渲完写 `out/sfx_manifest.json`（原则 B13）。

## 8. 交付前自查（顺序固定）

1. `measure_geom` + `measure_motion` 全绿；
2. 抽三帧（起手 / 动作中 / 收尾）看 1080 原像素，只答三个问题：
   读得清吗、被谁挡住吗、实体有没有接地；
3. 把上面三条判据的读数写进 `scenes/<id>.json` 的 `review` 段；
4. 负样本跑一遍（把已知画错的那版丢回去），判据要报红。
