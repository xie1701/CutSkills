# 陌生人照文档跑一遍 · 2026-11-07

**做法**：派一个没参加过任何讨论的 agent，只给它 `SKILL.md`（以及它指到的 references），
一句需求「用熊工在工地现场讲的原声，做一条 40 秒左右的竖版短片，讲讲国产和进口材料到底差在哪」，
让它从零建项目、做到文字粗剪为止。**不许读项目存档，不许改仓里任何文件**，遇到文档没说清的地方
记一笔再按自己的猜测继续。

**为什么这么做**：作者读自己的说明书，读的是「我写了什么」；陌生人读的是「实际写出来的」。
这两者差多少，只有陌生人跑一遍才知道——和第二轮盲测是同一个道理，只不过盲测测稿子，这个测文档。

## 结果

走通了：`index_assets → init_project → intake(thin) → --derive → build_takes_packed → search_library
→ plan.json → preview_plan ×2 → make_edl → render_paper_edit → check_edl(0 error) → gaps → view_diff
→ blind_test → log_decision`。

**6 段 / 39.94s / 4 个论点**，声音取自 `熊工口播2.MOV`，画面来自 5 支工地素材，`check_edl` 0 error。
它自己抽帧比对了 4 支素材的 L2 描述，发现一条不符（`码放涂料桶` 实际是工人在推桶），改了 `why`。

**被迫自己做决定 11 次。**

产物留在这份目录下的 `qizao-s01/`（已从素材库里搬出来，不影响真库）。

## 它列的卡点，以及这一次改了什么

| # | 它卡在哪 | 这次的处理 |
|---|---|---|
| 1 | 新库上 L2 怎么起步，文档没有一句按顺序的话 | SKILL.md A 段加「第一次跑一个库，顺序是死的」五步清单，并给出第一轮参数 `--l2-cap 60 --l2-per-asset 1` |
| 2 | `init_project` 的命令示例里没有 `--audience/--promise`，而后面又说「四个字段必须抽出来」——按构造只能先建后改 | 命令补全四个参数，并写明「先建再补就重跑同一条命令加参数」 |
| 3 | 项目放在 `/tmp` 会静默坏掉（往上三层找不到库，只抛 `FileNotFoundError`） | `make_edl` / `render_paper_edit` / `ab_open` 加 `--library`，找不到库时给中文解释；文档写明项目必须建在 `<库>/_cutskills/projects/<slug>` |
| 4 | `takes_packed.md` 尾部被截断，`--max-chars` 没写进文档 | 文档补一句「出现『已截断：素材太多』就调 `--max-chars` 或 `--include`，别以为那批素材没语音」 |
| 5 | `plan.json` 对 broll 段要写 `audio_asset/audio_in/audio_out`，文档只写「从哪句到哪句」，只写一组会切出哑片 | 文档写清两组时间的区别 |
| 6 | 整片都是 broll 时，「40s 内换介质」这条规则永远不触发（medium 从头到尾没变） | 判据改成「同质画面连续」：broll 连段按**素材**算。真项目数值 30.6s → 16.7s，不再是虚高或虚低 |
| 7 | 「盲测至少三种身份」一个人做不到；`--score` 收什么格式没写 | 改成「至少两位裁判，一位时不下结论」，并说明 `--score` 收原话文件、可多次 |
| 8 | `preview_plan` 只在超限时才印节奏那条 | 改成一直印（否则你会以为它没算） |

没改的：`intake` 在离线/无人可问时怎么办——那本来就是「问用户」的分支，属于人来做决定，不该由脚本猜。
