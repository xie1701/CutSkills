# MG 库：代码画的动效卡

**MG（motion graphics）** 在这里指的不是「加个动效」，而是**用代码画出来的一屏信息**：
数字、步骤、对比、术语。它跟实拍素材是互补关系——素材里没有的东西（规模、数量、因果结构），
只能靠画。

## 三层各管什么

| 层 | 决定 | 文件 |
| --- | --- | --- |
| 剪辑方案 `plans/*.yaml` | 骨架与节奏：这一格该长该短、该快该慢 | 不管 MG |
| 包装包 `packs/*.yaml` | **允许用哪几种 MG**、长什么样（tokens）、停在哪 | `mg.library` / `mg.rules` / `card.mg_top_h` |
| 时间轴 `timeline.json` | 这一格**具体用哪张 MG**、卡上写什么、锚在哪个词 | 元素上的 `card` |

一句话：方案管「什么时候该有一张卡」，包管「这张卡能长成哪几种」，时间轴管「这一张写什么」。

## 五种卡

| id | 长什么样 | 什么时候用 | 必填字段 |
| --- | --- | --- | --- |
| `keyword-big` | 一屏大字，单排、撑 70% 宽；可选压在人物脑后 | 一句话结论、强断言、要人记住的那几个字 | `text` |
| `stat` | 巨大数字 + 单位 + 一行说明 + 出处角标，数字从 0 滚上去 | 规模、金额、面积、数量、时长、比例 | `data.value` `data.unit`；`data.label`；`data.source` 或 `data.approx: true` |
| `steps` | 01/02/03 三个短条目，逐条滑入 | 两到三步的流程、并列条件、先后顺序 | `data.items`（≤3 条） |
| `versus` | 左右两栏 + 中缝 VS 弹出，可选尾句 | 两个时段、两个方案、两个做法的对比 | `data.left{head,body}` `data.right{head,body}`；可选 `data.tail` |
| `term` | 一个词 + 一句释义，释义后出 | 行话、方言词、品类词第一次出现 | `data.term` `data.def` |

## 选卡顺序（内容形态优先，不看风格）

1. 这一格的话里有**数字**吗 → `stat`
2. 有**两个东西在对立/对照**吗 → `versus`
3. 有**先后或并列的两三步**吗 → `steps`
4. 有一个**外行听不懂的词**吗 → `term`
5. 都不是 → `keyword-big`（把这句话压成 4–9 个字）

## 硬规矩

1. **一批片子里同一个卡型不重复超过 2 次**。三条 `stat` 连着出，观众会以为你在放 Excel。
2. **每条片至少一张内容专属卡**：有数字就必须有一张 `stat`，有对比就必须有一张 `versus`。
   全是 `keyword-big` 等于没做 MG，只是把字幕放大了一遍。
3. **卡上的话必须是台词里的原词**，不许另写宣传语。卡是「把说过的话画出来」，不是「再创作」。
4. **数字必须有出处**：讲得出是谁说的、哪一天说的，就写 `source`；讲不出来就 `approx: true`，
   画面右上角会自动挂「示意」。数字卡骗人比没卡更糟。
5. **不许压字幕带**（字幕中心 0.693H）、**不许压人脸**。卡的上沿由 `card.mg_top_h` 定，
   默认 0.21H；卡底边不许越过 `card.bottom_edge_max_px`（1080）。
6. 一屏只讲一件事：同一格里 MG 卡和大字撞了，**大字让开**（记 `deferred_to`），不要两件一起上。

## 时间轴写法

```json
"card": {
  "kind": "stat",
  "text": "两百平",
  "on": "两百平",
  "data": {"value": "200", "unit": "㎡", "label": "纯手工厨房，占总面积三分之一",
           "source": "牛哥口述 · 2026-10-22"}
}
```

- `on`：锚词，卡必须晚于它发音 +0.10s 出现（声音先出，画面跟着）。
- `data`：只有 MG 卡用；`keyword-big`/`behind` 只写 `text`。
- 卡的长度默认夹在 `emphasis.hold_s` 区间内，锚词说完了就收。

## 渲染实现

`scripts/render_hf.py`：`MG_KINDS = {"stat","steps","versus","term"}`，HTML + CSS 变量 + GSAP
逐件入场（数字滚动、条目错位、VS 弹出、释义后到）。颜色、圆角、描边全部走 `tokens`，
换包不用改代码：`tokens.palette.accent` 一改，五种卡一起换脸。

## 验收

- `check_packs.py`：包里的 `mg.library` 必须都是渲染器认识的 kind。
- `verify_film.py`：`out/cards.json` 里每张 MG 卡都要真的在画面上（三帧采样，不是看声明）。
- 目测：抽帧看卡有没有压脸、压字幕、卡上的字有没有被背景吃掉。
