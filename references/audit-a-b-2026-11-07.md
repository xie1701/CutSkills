## 三、原因与方案

### 甲类 · 需求本身没想清（先把话说清，别急着写代码）

| 问题 | 判定 | 方案 |
|---|---|---|
| A6 内嵌字幕到底是需求还是残留 | 砍掉更符合奥卡姆：L2 的 `text_on_screen` + `flags` 已经回答"有没有字"，"字在哪能不能避开"是 D 段构图的事 | BRIEF 阶段 A 表删掉"内嵌字幕"，进「砍掉的」并写代价：烧了字的素材竖屏重排时去不掉字，只能裁或选别的段 |
| A9 说话人标注出现在 v1 的 L1 | 放错版本：v1 是单机位单人，这一项属于 v1.5 访谈 | 移出 v1。v1.5 时先确认 `coli asr` 无 diarization（已查：只有 whisper/sensevoice 两个模型，无说话人参数），方案是"用 L2 每段的 `people` 把该段内的短语归给这个说话人"，不需要新模型 |
| A12 的 15% 是成本约束还是质量约束 | 现在两面都不成立：超了没人知道，也没定义超了会怎样 | 改成可测指标：`finish` 时算 `l2_coverage = L2 段总时长 / 库总时长`，写进 `counts`，超 0.15 打 warning；同时写清"为铺整库命名可以超，超了要在这份索引里留一行原因" |
| A20 抽帧分三档 | 过度设计：取用单位是镜头段，2s 一帧够 | 降级为固定 2s，BRIEF 那条删掉，在 SKILL 的「已知的坑」补一句"别按题材调密度，收益不抵复杂度" |
| A19 转写降级链 | 文档写的两条路都死了（ElevenLabs 欠费、hyperframes 断流），照文档走就是浪费时间 | 文档改成"只有 coli 一条路；失败就停并要求人工"。要真降级再写 fallback，但先把假选项删掉 |
| B6 `confidence` 是谁的置信度 | BRIEF 混了两个东西：L2 对画面的置信、人对取舍的置信。只有前者能机器算 | 字段改名 `grade_confidence`，从 L2 同区间段透传；不伪造人的置信度 |
| B16 两个参数 | "参数化"是 v1.5 的承诺，v1 只有一个取值，做成分支就是空转 | v1 只做取值校验 + 与 `medium` 的组合校验（如 `cut_source=speech` 时不许出现 `manual` 段）；行为分支留到 v1.5，文档写明"参数先约定、后生效" |
