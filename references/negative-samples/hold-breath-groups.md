# 字幕停留：单呼吸组豁免的正/负样本（T-029，2026-11-13）

`check_subs.HOLD_MAX = 3.2` 量的是「一句话赖在屏幕上」，它量不出**语速**。
慢语速的人一口气真能连着讲 3.3–4.1 秒，而 `subs.py` 的规则是「只在停顿处拆」
（`GAP_BREAK = 0.30`）——两条规则在慢语速上互锁，`qizao-ground-01` / `proj79`
那几条 3.30–4.08s 的字幕拆不出来也判不过。

2026-11-13 只加了一条豁免，判据本身（3.2s 硬红）不动：

| 窗口里**实量**到的最长静音 | 上限 |
|---|---|
| < 0.30s（单呼吸组：一口气没断） | `HOLD_MAX_SINGLE = 4.5s` |
| ≥ 0.30s（换过气），或**量不出**（素材不在、ffmpeg 起不来） | `HOLD_MAX = 3.2s`（照旧） |

静音一律用 `silence.runs()` 量真电平，**不看 ASR 词起点间隔**：ASR 会漏词，也会把停顿
记进某个字的时长里（`ground-01` 那句「其中有」的「有」占了 1689.60–1691.22），
拿间隔猜停顿，就会把「真停过 1.2 秒」当成「连着讲的」。

跑法（素材库默认 `/Users/jerry/Downloads/柒造Video/素材`，可用 `CUTSKILLS_LIB` 换）：

```bash
python3 scripts/test_hold_breath.py
```

样本在 `hold-breath-groups.json`，全部取自本机真实素材。每条断言都走产线函数
`check_subs.make_hold_probe()` / `hold_judge()`，测试自己一个判据都不写。

- 单呼吸组 5.0s → 判红（4.5s 是天花板，不是「长就放行」）。

## 这一条**没有**解决的事（别把豁免当成拆条）

量下来 `ground-01` 四条长条里只有 **1 条**（3.30s「包括房地产的售楼部」）是真单呼吸组；
另外三条窗口里都有 0.46–1.22s 的真静音（`ffmpeg -af volumedetect` 实测 −55dB 量级，
见 T-029 报告），说明说话人**确实停过**，只是 ASR 把那段停顿算进了某个字的时长里，
`subs.py` 按字起点间隔看不到它。这三条继续判红是对的；要让它们真正过，
得让拆条也去量真静音（`silence.runs()`），那是改产线，不在 T-029 范围。
