# Built-in CC0 1.0 Universal Starter BGM Pack

全部曲目按 **CC0 1.0 Public Domain** 口径收录。

来源：本地策展库 `cc0-bgm-library`（其许可声明见该库的 `SOURCES.md` / `CATALOG.md`）。

**如实记录的局限（评审 P0-06）**：逐曲的原始发布页 URL 与作者署名未随音频文件一起保存，
本目录只能给出整库口径的声明 + 文件哈希。商用批量交付若需逐曲许可证明，
请在外置库补齐 per-file 元数据（`source_url` / `author` / `retrieved_at`）后再引用；
`cc0_lib.licence_of()` 只认**带许可留痕文件**（`LICENSE-CC0.txt` 或 `SOURCES.md`）的库根，
没有留痕的外置素材在成片 `out/sfx_manifest.json` 里会标成「未核实」而不是 CC0。

内置曲目清单与标签见同目录 `catalog.csv`；每首的 sha256 记在成片的 `out/sfx_manifest.json`。
